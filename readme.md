# VIN Decoder

SPA для розшифровки автомобільних VIN-кодів через відкрите API [NHTSA vPIC](https://vpic.nhtsa.dot.gov/api/).

🔗 Розгорнутий застосунок: _додайте посилання після деплою_

## Функціонал

- **Головна сторінка (`/`)** — форма введення VIN-коду з валідацією (непусте поле, не більше 17 символів, лише латинські літери й цифри без I/O/Q), список результатів розшифровки (лише заповнені характеристики) та історія трьох останніх запитів із можливістю повторного перегляду результатів без повторного звернення до API.
- **Сторінка `/variables`** — список усіх змінних, які повертає API, з посиланнями на детальний опис.
- **Сторінка `/variables/:variableId`** — назва, ідентифікатор та опис конкретної змінної.
- Помилки валідації форми та повідомлення з поля `Message` відповіді API відображаються в інтерфейсі.
- Історія запитів зберігається в `localStorage` і переживає перезавантаження сторінки.
- Клієнтський роутинг реалізовано через `HashRouter`, тому застосунок коректно працює на GitHub Pages без додаткових налаштувань 404-редіректу.

## Технології

React 18, TypeScript, React Router, Vite. Верстка — семантичний HTML і чистий CSS (без UI-фреймворків), адаптивна від 420 до 1440 px.

## Локальний запуск

Потрібен [Node.js](https://nodejs.org/) v18+.

```sh
npm install
npm run dev
```

Застосунок буде доступний за адресою, яку виведе Vite (типово `http://localhost:5173`).

### Збірка

```sh
npm run build
npm run preview
```

## Деплой

Проєкт готовий до деплою на Vercel, Netlify або GitHub Pages (`npm run build`, папка `dist`).

Для GitHub Pages за адресою `https://<user>.github.io/<repo>/` встановіть у [vite.config.ts](vite.config.ts) `base: '/<repo>/'` перед збіркою. У репозиторії налаштовано workflow [`.github/workflows/static.yml`](.github/workflows/static.yml), що автоматично збирає та публікує проєкт на GitHub Pages при пуші в `main`.
